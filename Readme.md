# InvoiceFlow

> A professional Windows desktop application for bulk invoice generation from Excel and CSV files.

InvoiceFlow converts structured Excel/CSV invoice data into professional PDF invoices through a simple desktop interface.

## ✨ Features

- Excel and CSV input support
- Smart input validation and column mapping
- Structured invoice data processing
- Professional PDF invoice generation
- Bulk invoice processing
- Automatic output-folder management
- Duplicate invoice-number detection
- Production-grade error handling
- Real-time processing progress
- Windows desktop GUI
- Standalone Windows EXE
- Windows installer support

## 🛠️ Tech Stack

- Python
- PySide6
- pandas
- ReportLab
- openpyxl
- xlrd
- pywinstyles
- PyInstaller
- Inno Setup
